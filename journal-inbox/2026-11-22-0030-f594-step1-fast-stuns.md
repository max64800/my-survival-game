# 2026-11-22 — F594 Step 1: Fast stuns (Valheim-style)

## What we did
Built Step 1 of the hit-feel plan: switched the stun meter from fixed stun-per-weapon-hit to
Valheim-style **damage × stun type factor**, so combos now stun in a satisfying rhythm.

Changes:
- **`combat.gd`**: added `STUN_FACTOR = {blunt: 1.5, slash: 1.0, pierce: 0.8}` and rewrote
  `stun_value(w, heavy, tier, combo_step)` — now returns `base_damage × tier_scale × combo_mult × stun_factor`.
  Parry stun values (absolute 40/25) stay exactly as they were.
- **`monster_manager.gd`**: passes `combo_step` into `stun_value()` so later combo hits count harder.
- **`monsters.gd`**: stun thresholds reset to ~45% of max HP for normals (was ~70-100%), ~60% for the elite
  beetle, ~80% for both bosses. The old values were calibrated for the old formula and far too high.
  - rock_snail 90→50, rock_beetle 70→45, great_rock_beetle 160→144, cave_spider 30→13,
    tunnel_rat 30→12, lost_miner 80→50, foreman 220→360, prop_warden 200→240.
- **`test_monsters.gd`**: updated `test_parry_stuns_the_monster` — a parry (25 stun) now fully stuns a
  cave spider outright (stun_max=13) so the old exact-value check was updated.
- **`test_combat.gd`**: updated the mace/sword ratio check from `> 2.0` to `> 1.4` (new formula gives 1.65×,
  still clearly mace > sword, just not 2.5× as before).
- **`tests/test_hit_feel_stun.gd`** (new): 10 tests counting hits-to-stun per weapon vs each monster.

## Mistakes and hurdles
- First parse error in the new test: `var combo_size := ...` couldn't infer the type from a Dictionary
  value. Fixed by casting `(combo as Array).size()` with an explicit `int` type annotation.
- `test_parry_stuns_the_monster` broke because cave_spider stun_max (13) is now smaller than the parry
  stun (25), so one parry stuns it outright and `stun.value` resets to 0. Updated the check to accept
  either "spider is stunned" or "value ≥ STUN_WEAPON_PARRY".
- Running `only=test_combat,test_hit_feel_stun` together returned "0 checks" (probably a comma-sep parsing
  issue in run_tests.sh). Ran them separately; each passed correctly.
