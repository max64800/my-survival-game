## Nov 22 (PC, night): the hitbox viewer wasn't showing up (F696)

**What happened**
Another Claude built the hitbox viewer earlier today — press a key, see yellow/orange rings
around monsters and a blue outline on the dwarf, so the owner can check if hits are landing
in the right spot. It used **F9** to turn on and off.

The owner tried it and said it didn't work. Turns out F9 was already taken: it's the key for
"god mode" (nothing can hurt you), which has been in the game since Nov 20. Two different
things were both listening for the same key press — pressing F9 only ever flipped god mode
on and off; the hitbox viewer never got a turn.

**The fix**
Moved the hitbox viewer to **F10** instead, so the two don't fight over the same key anymore.
Also made it tell the game "I used this key press" when it toggles, so if anything else is
ever listening for F10 too, it won't double-fire by accident (a small safety habit, not
a bug we actually hit this time).

**Why this is worth writing down**
Two separate pieces of code each grabbed a raw key (F9) without checking if anyone else
already had it. The game has a proper "list of all the keys" file (`controls.gd`) for this
exact reason — most keys go through it. The hitbox viewer skipped that list and just
hard-coded F9 straight into its own file, which is how it snuck past without anyone noticing
the clash until the owner tried it. Next time a debug key gets added, check that list first.

**Files touched:** `src/ui/hitbox_debug.gd` (F9 → F10, marks the key press as handled),
`FEEDBACK.md` (F696 marked done).
