## 2026-11-23 (PC) — Carry weight: heavy loads slow you down (F793)
- **Settled with the owner first (grill, 2 rounds + 1 extra):** two-step slowdown (free up to "heavy", then gently
  slower, then OVERLOADED), heavy at 200 / overloaded at 300 (stone = 1), worn gear counts half, overloaded = 40% speed
  with no sprint, dodge or jump, still picks things up. Limits go up with the Leather Satchel (+60), the Deep Pockets
  perk, food "carry" buffs, and later backpacks. Mid-chat the owner added stack sizes: now by kind with round numbers
  (stone/ore/wood 50, bars/crystals 30, food 20, drinks 10, ammo 100). Record: `docs/decisions/2026-11-23-carry-weight.md`.
- **Built:** `src/items/item_weights.gd` holds every number (weights by kind and by item group, stacks, limits, the
  slowdown math). Small hooks only: `Items.stack_size` asks it for the default stack, `Inventory.load_data` splits
  old saves' 100-stacks into free slots (never deletes; a full bag keeps the big stack), `Dwarf._update_carry` checks
  the load 5 times a second and multiplies the speed, overloaded blocks jump (dwarf.gd) and dodge (dwarf_fight.gd).
  HUD: "Weight 142 / 200" under the Bag title, yellow "Heavy" / red "OVERLOADED" inside the stamina bar's left end,
  and every item's hover text shows its weight.
- **Co-op:** the host already owns each inventory and sends it to its player; the weight table is the same code on
  every PC, so each player's own dwarf works out its own slowdown. Nothing new to sync.
- **Tests:** `tests/test_carry_weight.gd` (every item has a real weight, the owner's table, stacks, worn half,
  two-step slowdown, satchel/perk/food bonus, old stacks split, and a live dwarf that is overloaded: slower, no jump,
  no dodge). `tests/test_inventory.gd` now reads the stone stack size instead of a fixed 100.
- **Hurdles (Claude's own):** (1) the design doc still said "No weight limit, only slots matter", so I replaced that
  line. (2) The owner picked "Deep Pockets +50", but the perk has 3 ranks, so I made it +25 per rank (+75 at full) and
  told the owner. (3) Food buffs are capped fractions (50%), so a food "carry" buff means +X%, not +50 weight.
  (4) The first "every item has a weight" test caught the empty waterskin (its own kind); added it.
  (5) Three old bag tests assumed stone stacks to 100; changed them to read the real stack size.
- Talked with the food chat (F426) before editing hud.gd. Their food row sits right of the bars, so the overload word
  went inside the stamina bar on the left end instead of a badge beside it.

  dwarf test switched the test runner's "robot" mode off at its end, so test_save later found it off. Fixed both.
  The rest came from other chats' unsaved work: the caves came out with no roots, crystals or drips (unsaved
  world.gd / cave_maker.gd edits), and the food chat was mid-edit on `has_room_for`. My code doesn't touch any of that.
- Also shortened the stamina-bar word to "HEAVY" / "OVERLOADED" so it can't run into the food chat's new centred
