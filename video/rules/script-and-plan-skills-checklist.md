**Every script or rewrite (long form, Shorts, ads), before showing it to Max:**
1. Read: `video-scripts/talking-head-rulebook.md` (55 rules + pre-record checklist), `.claude/skills/eqt-script-doctor/SKILL.md`, [[script-self-review]], [[ten-hooks-every-script]] (10 hooks, top 3, labelled on the hook ladder), [[jenny-hoyos-formula]] (adapt for long form: problem + promise early, end after the payoff), the 5-point audience check in [[reference-batch-10-2026-10-25]], [[say-full-place-in-dubai]], [[script-5th-grade-rule]], [[content-direction]], [[max-paraphrases-scripts]], [[youtube-publishing-rules]] (long form), like for like (in eqt-script-doctor rule 11b).
2. Load and apply with the Skill tool (not "mentally"): `humanizer`, `stop-slop` (give the /50 score), `storytelling-hooks` (3 hook layers: frame 1, spoken line, overlay that carries the other half of the gap; bookend the ending).
3. Measure the reading grade with textstat and report it.
4. Fact check every statement per [[fact-check-every-statement]].
5. Audit table: one row per rule or skill, saying what it changed. Only list a skill as passed if it was run in this session. If something was skipped, say "skipped" and why.

**Every video plan or editor brief:**
1. Load and apply the `b-roll-shot-list` skill: filming order, one line per shot, essential vs nice to have, orphans cut, stock fallback, kit.
2. Read: [[broll-rules]], [[edit-hard-rules]], [[longform-template]], [[longform-ep3-feedback]] (real aerial maps, a credit on every clip, no loops, no shot twice, no flash frames, vertical bars for heights), [[graphics-layout-qa]], [[cut-timing-hard-rules]], [[longform-youtube-setup]].
3. For any Nakheel project, read [[nakheel-broker-guidelines]] first: their footage full screen and uncropped with nothing on it, or in its own window beside our graphics; never crop, punch in, grade or cover it; Nakheel Marketing (agents@dhre.ae) approves before it goes live; give Max the approval email draft.

**How to apply:** treat this file as the checklist at the start of any script or plan task, in this project or from the EQT New Website project. Related: [[script-self-review]], [[ten-hooks-every-script]], [[nakheel-broker-guidelines]].
